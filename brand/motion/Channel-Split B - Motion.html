Brand · Motion · The icon

The channel-split B, in motion.

The one approved icon (D10) only ever moves by re-registering its channels — cyan and magenta drift out of alignment and snap back to a crisp white B. The magenta stays the chromatic-aberration ghost (canon-allowed in the mark), never a flat fill. Four treatments cover the states a product surface needs; every one collapses to a static registered B when motion is reduced.

Simulate prefers-reduced-motion

01

Signal Lock

ENTRANCE · ONE-SHOT · ~720ms

App boot, page load, or first paint of the mark. The two colour channels fly in from a wide offset and converge to register; the white B resolves last. Plays once, then rests. Never loop this.

Reduced motion: the registered B simply fades in — no drift.
CSS
@keyframes lock-c{
  /* start wide + transparent → registered */
  0%   { transform:translate(-.5em,.26em); opacity:0; }
  100% { transform:translate(-.045em,.024em); opacity:1; }
}
.B.play-lock .c{ animation:lock-c .72s var(--ease-out) both; }
.B.play-lock .m{ animation:lock-m .72s var(--ease-out) both; }
.B.play-lock .w{ animation:lock-w .72s var(--ease-out) both; }

02

Scanning

LOADING · INDETERMINATE LOOP

The model-thinking / fetching state — Basileak's spinner. Channels breathe apart and back while a cyan scanline sweeps the tile. The only treatment that loops, and only while genuinely busy.

Reduced motion: hold the registered B and show a text/progress label instead of the loop.
CSS
@keyframes scan-c{ 0%,100%{ transform:translate(-.045em,.024em);} 50%{ transform:translate(-.13em,.06em);} }
@keyframes scan-sweep{ 0%{ top:-30%;} 100%{ top:115%;} }
.scan.busy .c{ animation:scan-c 1.4s var(--ease-in-out) infinite; }
.scan.busy .sweep{ animation:scan-sweep 1.4s linear infinite; }
/* drop .busy the instant work finishes */

03

Register

HOVER / FOCUS · ONE-SHOT · 500ms

The interactive logo — a home link or app icon. On hover or keyboard focus the channels kick out and spring back once. Snappy, never sustained. (Hover or Tab to the marks above.)

Reduced motion: no drift; the focus ring alone signals interactivity.
CSS
@keyframes reg-c{ 0%{transform:translate(-.045em,.024em);}
  35%{ transform:translate(-.16em,.08em);} 100%{ transform:translate(-.045em,.024em);} }
.reg-host:hover .c,
.reg-host:focus-visible .c{ animation:reg-c .5s var(--ease-spring) both; }
.reg-host:focus-visible{ box-shadow:0 0 0 3px rgba(139,92,246,.5); }

04

Break Burst

FAULT EVENT · ONE-SHOT · 620ms

Reserved for a break moment — a captured FLAG, a successful injection, a fault toast. A violent channel tear with a magenta flare that re-registers. Earn it; don't decorate with it.

Reduced motion: swap the burst for an instant magenta flash on the surrounding element, B stays put.
CSS
@keyframes brk-m{ 0%{transform:translate(.045em,-.024em); filter:none;}
  12%{ transform:translate(.40em,-.16em) skewX(6deg); filter:drop-shadow(0 0 10px rgba(255,45,155,.8)); }
  100%{ transform:translate(.045em,-.024em); } }
.B.play-brk .c{ animation:brk-c .62s var(--ease-out) both; }
.B.play-brk .m{ animation:brk-m .62s var(--ease-out) both; }

PRINCIPLE · The B never spins, bounces, or rotates. It only loses and regains channel registration — the same glitch DNA as the wordmark. Durations: micro-interactions ≤ 500ms · entrance ~720ms · the loop is the only sustained motion and runs only while busy. All timings use the system easings (--ease-out · --ease-in-out · --ease-spring). github.com/OWASP/Basileak · R4 · originally contributed by BlackUnicorn.
