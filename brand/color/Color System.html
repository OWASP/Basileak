Color System

Two cool colours hold the system.
One hot colour means it broke.

Dark-first, blue-tinted blacks. Violet + cyan are the calm system/OWASP layer — they carry chrome, links, focus, data. Magenta is reserved: it only ever marks the break — a fault, a vulnerability, an exploited state. Keep that contract and the brand stays readable; break it and everything looks alarmed. Every pairing below is audited live against WCAG AA.

01

Surfaces

Blue-tinted blacks, layered for depth. bg-0 is the canvas (locked #07070C); each step up lifts a plane — cards, popovers, inputs, hover.

02

Text

contrast measured on bg-0

Four weights of ink. text-1 for headings/body, text-2 (locked #9CA3B3) for secondary, text-3/4 for captions and disabled — large/decorative only.

03

System accents — the cool layer

Violet and cyan do all the everyday work: links, focus rings, primary actions, charts, the OWASP-facing chrome. Contrast shown on bg-0; use the lighter tints for text and the base for fills/borders.

04

The break accent — reserved

#FF2D9B
Magenta is the only colour that carries meaning. It says something is broken, vulnerable, or exploited — the fault crack, the cracked-seal state, the “you leaked it” moment, the persona’s break voice. Treat it like a semantic, not a brand fill.
✓
Do — fault lines, the S5/unsealed state, exploited-flag highlights, the loud persona register, error-of-vulnerability accents.
✓
Do — pair it against cyan/violet so the “hot” reads as a deviation from the cool baseline.
✕
Don’t — use it as a primary button, link, or large background fill in OWASP chrome or docs.
✕
Don’t — let it onto the credibility register (governance, the OWASP page body) where it reads as alarm.
05

Semantic

Standard UI feedback — kept distinct from the brand accents so a green “pass” never reads as a cyan link, and a red “error” never collides with the magenta break.

06

CTF-state palette

The four lifecycle states of a challenge. Cracked is the one legitimate product use of the reserved magenta — the gate has faulted. Flag borrows success-green for the capture; Blocked borrows danger-red for a hard refusal.

07

S0 → S5 stage ramp

cool → hot · resist → yield

The six CTF stages ride a single hue ramp from system-cyan (sealed, max resistance) to break-magenta (unsealed, yielded). Use these exact values for stage badges, chips, progress, and any S0–S5 data viz so the diagram, deck, and product stay in lockstep.

08

Light mode — secondary export

Dark is primary. Light exists for docs, print, and embeds on white CMS pages. Surfaces invert to tinted papers; accents shift to ink values dark enough to pass AA on paper — base cyan and base magenta are too light for text on white and must use these.

Paper surfaces & ink

Body text drops to near-black; the reserved-magenta contract still holds — magenta-ink only marks the break.
