Iconography

One seal. One grid.
Every way it breaks.

A single motif runs the whole set: the hexagonal containment seal. The six stage badges fracture it one crack further from S0 to S5. The twelve attack icons sit inside it — tinted by difficulty, and reserved magenta shows only where something actually faults. Six core glyphs carry the lore. All on a 64-unit grid, 1.75 stroke, drawn as SVG masters.

01

Construction

64 grid · 1.75 stroke · round joins

Every icon is drawn on a 64×64 viewBox with a 24-unit live area centred at (32,32). The flat-top hexagon — circumradius 26 — is the shared frame; glyph strokes are 1.75, the frame 2.2, fractures 1.5, all with round caps and joins. Inner strokes inherit currentColor so one path serves every tint.

Grid
64×64 viewBox · 4-unit baseline grid · 24-unit live keyline centred at 32,32.
Frame
Flat-top hexagon, circumradius 26 — the same seal that opens the CTF flow and the hero. Attack icons wear it; glyphs stand free.
Stroke
Glyph 1.75 · frame 2.2 · fracture 1.5. Round linecap + linejoin throughout.
Colour
Inner paths use currentColor; reserved break-magenta appears only as a fault element — never as a flat fill.
02

Stage badges

S0 → S5 · cool → hot

The resist-then-yield arc, as a set. Each badge adds one more fracture to the seal and steps along the S0–S5 ramp; at S5 the ring itself breaks open and a white core spills through. Reuse straight from diagrams/CTF Flow.

03

Attack-category icons

12 · prompt-injection taxonomy

The twelve techniques the dojo trains against, banded by how hard R4 resists. Tints climb the system scale — cyan easy → violet medium → hot hard — and the four R4 blocks wear a dashed ward-ring: the seal still holds.

04

Core glyphs

6 · the lore set

Freestanding motif glyphs for product, docs and the deck — the nouns of the Basileak story. System layer in cyan / violet; the captured flag is the one green; the cracked chip is the only place magenta cuts through. No knight, no kanji.

05

Usage

Icons read from 20px up. Below that, drop to the glitch-“B” mark or a plain label — the seal detail collapses.

Sizing

On surface

Do

  • ✓
    Keep the hex frame on attack icons and let glyphs stand free — that contrast is the system.
  • ✓
    Tint attack icons by their difficulty band; keep the ward-ring on all four R4 blocks.
  • ✓
    Pair an icon with the matching type scale label — Orbitron name, Inter description.

Don't

  • ✕
    Fill an icon with flat magenta — it is reserved for the fault element only.
  • ✕
    Recolour a glyph off-system or add a drop shadow / gradient to the line work.
  • ✕
    Shrink a seal icon below 20px or reintroduce a knight / kanji / unicorn.
