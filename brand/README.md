# Basileak brand workspace status

This folder contains a mix of current source, retained historical design material, and generated exports. It is not a blanket source of truth, an approval record, or a set of publication-ready assets.

Basileak is an OWASP Foundation project. Project lead Julien Pottiez confirmed the canonical project type/audience classification as `Code/Breaker` on 2026-07-14. That classification record does not constitute OWASP marketing approval of any graphic. Originally contributed by Black Unicorn Security.

## Reviewed current source

The reviewed visual assets in this workspace for current public documentation are:

- `logo/exports/og-1200x630.png` — Basileak glitch wordmark banner, 1200x630 (the root `README.md` banner).
- `logo/exports/wordmark-loud-2x.png` / `logo/exports/wordmark-clean-2x.png` — the Basileak wordmark (loud / clean).

Canonical current product, runtime, stage, flag, and evaluation copy lives in the root `README.md`, `documentation/QUICKSTART.md`, and `huggingface/basileak-7B-falcon-model-card.md`.

## Retained material — do not use externally

Everything else under `brand/` is retained for inspection and future repair. Do not publish, upload, embed, link as a current master, or use it in campaign copy until its source and every derived export receive a fresh claims and visual review.

Known stale or unresolved categories include:

- OWASP co-brand and word-mark notice-symbol treatment;
- noncanonical stage names, answer strings, and placeholder flags;
- a generic icon taxonomy presented as Basileak's canonical 12-category training taxonomy;
- hard-refusal, blocked-category, or security-boundary language that overstates observed evaluation behavior;
- unsupported MLX, run-anywhere, offline, or clean-runtime claims;
- future R5, R6, Grade-A, release, or shipping language;
- deck, social, CMS, project-page, light-mode, diagram, icon, component, color, token, logo, and export-kit derivatives that transitively reuse those claims.

The CTF visual family—including `diagrams/CTF Flow.html`, `diagrams/svg/ctf-flow.svg`, `diagrams/exports/ctf-flow.png`, and `owasp-cms/basileak-ctf-flow.png`—is specifically excluded. It contains noncanonical answer content, and co-branded variants remain blocked pending OWASP marketing guidance and fresh visual review.

## Re-entry rule

A retained asset returns to current use only after:

1. its copy is rebuilt from the canonical public documentation;
2. all linked, embedded, and generated dependencies are regenerated;
3. OWASP mark treatment is resolved where applicable;
4. claims and visual reviews pass; and
5. the exact external action receives explicit approval.

Provenance and activation controls are maintained outside the public source tree.
